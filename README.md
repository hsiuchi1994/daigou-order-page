# 代購訂購頁面

消費者免登入下單頁面，前台為客製化 HTML（GitHub Pages 託管），資料存放在你既有的代購 Google Sheet，透過 Google Apps Script 當免費 API。

店名、公告、圖片、商品、下單規則全部在 Google Sheet 修改，不需要碰程式碼。

## 首次設定（只需做一次）

### 1. 擴充 Google Sheet

1. 打開你的代購試算表「開團表單」（含「定價試算 / 運費試算」分頁的那份）
2. 上方選單 **擴充功能 → Apps Script**
3. 把 `apps-script/代購訂購系統_setup.js` 的內容整個貼進去
4. 執行 `setupOrderSystem` 函式（第一次執行會要求授權，允許即可）
5. 執行完成後回到試算表，會看到：
   - `定價試算` 最右邊多了 **商品介紹**、**圖片網址** 兩欄
   - 新增 `網頁設定` 分頁：店名、標語、橫幅圖片、公告
   - 新增 `下單規則` 分頁（範例文字先幫你填了 3 條，直接改成你自己的規則）
   - 新增 `訂單總覽` 分頁：一筆訂單一列，含總金額與「處理狀態」下拉選單
   - 新增 `訂單` 分頁：一個品項一列，方便統計要採購的數量

### 2. 部署 API（Apps Script Web App）

1. 同一個 Apps Script 專案裡，新增一個檔案 `Code.gs`，貼上 `apps-script/Code.gs` 的內容
2. 右上角 **部署 → 新增部署作業**
3. 類型選 **網頁應用程式**
4. 設定：
   - 執行身分：**我**
   - 具有存取權的使用者：**任何人**
5. 部署後複製產生的網址（結尾是 `/exec`）

> 之後如果 `Code.gs` 有更新，要到 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址才會維持不變。

### 3. 設定前台網址

1. 打開這個 repo 的 `config.js`
2. 把 `API_URL` 換成上一步複製的網址
3. 存檔、`git commit` + `git push`，GitHub Pages 會自動更新

### 4. 分享編輯權限給合夥人

- 把 Google Sheet 分享給合夥人，權限設為「編輯者」
- 合夥人之後只要在 Sheet 裡修改，前台頁面重新整理就會自動更新

## 日常維護（全部在 Google Sheet）

| 想做的事 | 去哪裡改 |
|---|---|
| 改店名、標語 | `網頁設定` 分頁 |
| 發公告 | `網頁設定` 新增一列，A 欄填「公告」、B 欄填內容；不要了就清空 B 欄 |
| 換橫幅圖片 | `網頁設定` 的「橫幅圖片」 |
| 上架新商品 | `定價試算` 新增一列，「上架與否」填 **Ｏ**（O、○、是 也可以），填好實際售價、商品介紹、圖片網址 |
| 下架商品 | `定價試算` 該列「上架與否」清空 |
| 修改下單規則 | 直接改 `下單規則` 分頁裡的文字 |
| 收款、追進度 | `訂單總覽` 分頁，改「處理狀態」欄 |
| 統計要買哪些商品 | `訂單` 分頁（可用篩選或樞紐分析表依商品加總數量） |

### 圖片怎麼放

兩種都可以：

- **一般圖片網址**：在圖片上按右鍵 →「複製圖片網址」
- **Google 雲端硬碟**：把圖片上傳到雲端硬碟 → 右鍵「共用」→ 一般存取權改成 **「知道連結的任何人」** → 複製連結貼到 Sheet。程式會自動轉成網頁可顯示的格式

建議開一個共用資料夾專門放商品圖片，資料夾設定好「知道連結的任何人」，放進去的圖片就都不用再個別設定。

## 本機測試

```bash
python3 -m http.server 8000
```

開啟 http://localhost:8000，注意 `config.js` 裡的 `API_URL` 必須已經指向真實部署的網址才能看到商品資料。

## 架構說明

- 消費者全程停留在同一個頁面，不會跳轉到 Google 網域
- 消費者不需要登入；勾選「記住我的資料」後，姓名、電話、LINE ID 只存在客人自己的瀏覽器，下次自動帶入
- 消費者看不到其他人的訂單（訂單只寫入 Sheet，前台不會顯示任何人的歷史訂單）
- 網頁依 `定價試算` 第一列的標題找欄位（商品名稱（中文）、實際售價、上架與否、商品介紹、圖片網址），欄位可以插入或搬動，但這幾個標題文字不要改
- 訂單金額以 Sheet 上的售價為準，不採用前台送來的價格
- 完全免費：GitHub Pages + Google Apps Script + Google Sheets 皆無使用費用
