# 代購訂購頁面

消費者免登入下單頁面，前台為客製化 HTML（GitHub Pages 託管），資料存放在你既有的代購 Google Sheet，透過 Google Apps Script 當免費 API。

## 首次設定（只需做一次）

### 1. 擴充 Google Sheet

1. 打開你的代購試算表（含「定價試算 / 運費試算 / 上架商品」三個分頁的那份）
2. 上方選單 **擴充功能 → Apps Script**
3. 把 `apps-script/代購訂購系統_setup.js` 的內容整個貼進去
4. 執行 `setupOrderSystem` 函式（第一次執行會要求授權，允許即可）
5. 執行完成後回到試算表，會看到：
   - `定價試算` 多了 **M 商品介紹**、**N 圖片網址** 兩欄
   - 新增 `下單規則` 分頁（範例文字先幫你填了 3 條，直接改成你自己的規則）
   - 新增 `訂單` 分頁（消費者下單後會自動寫入這裡）
6. 到 `定價試算` 幫每個要上架的商品填寫 **商品介紹** 和 **圖片網址**（圖片網址可以用 Google 圖片直接複製圖片網址，或任何公開圖片連結）

### 2. 部署 API（Apps Script Web App）

1. 同一個 Apps Script 專案裡，新增一個檔案 `Code.gs`，貼上 `apps-script/Code.gs` 的內容
2. 右上角 **部署 → 新增部署作業**
3. 類型選 **網頁應用程式**
4. 設定：
   - 執行身分：**我**
   - 具有存取權的使用者：**任何人**
5. 部署後複製產生的網址（結尾是 `/exec`）

### 3. 設定前台網址

1. 打開這個 repo 的 `config.js`
2. 把 `API_URL` 換成上一步複製的網址
3. 順便把 `SHOP_NAME`、`SHOP_TAGLINE` 改成你的店名和標語
4. 存檔、`git commit` + `git push`，GitHub Pages 會自動更新

### 4. 分享編輯權限給合夥人

- 把 Google Sheet 分享給合夥人，權限設為「編輯者」
- 合夥人之後只要在 Sheet 裡改「商品介紹 / 圖片網址 / 下單規則」，前台頁面重新整理就會自動更新，不需要碰任何程式碼

## 日常維護

| 想做的事 | 去哪裡改 |
|---|---|
| 上架新商品 | `定價試算` 新增一列，K 欄「上架與否」填「是」，填好商品介紹/圖片網址 |
| 下架商品 | `定價試算` 該列 K 欄改回「否」 |
| 修改下單規則 | 直接改 `下單規則` 分頁裡的文字 |
| 查看訂單 | 打開 `訂單` 分頁，每個訂單編號對應一到多列（一列一個品項） |
| 換了 Apps Script 部署網址 | 更新 `config.js` 的 `API_URL` 後 push |

## 本機測試

```bash
python3 -m http.server 8000
```

開啟 http://localhost:8000，注意 `config.js` 裡的 `API_URL` 必須已經指向真實部署的網址才能看到商品資料。

## 架構說明

- 消費者全程停留在同一個頁面，不會跳轉到 Google 網域
- 消費者不需要登入，也看不到其他人的訂單（訂單只寫入 Sheet，前台不會顯示任何人的歷史訂單）
- 完全免費：GitHub Pages + Google Apps Script + Google Sheets 皆無使用費用
